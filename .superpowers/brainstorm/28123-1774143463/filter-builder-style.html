A: Inline Row Builder

Each condition is a row with dropdowns: [Field] [Operator] [Value]. Groups are visually boxed. Compact and scannable — similar to Datadog/Sentry filter UIs.

B: Stacked Card Builder

Each condition gets its own card with a labeled field type and rich input (pills for multi-select, text for regex). More spacious, easier to read at a glance. Each field type gets a tailored input widget.
